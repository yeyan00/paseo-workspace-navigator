Workspace Navigator shows your Paseo workspaces in a collapsible host, project and workspace tree. Search by host, project, directory, workspace or branch, then open a workspace on its owning host. It adds a sidebar entry and a separate navigation screen.

Create workspaces with the project's plus button, sharing project files or using an isolated Git worktree. Continue in Paseo's native workspace interface to select a model and chat. Workspace menus offer renaming, copying paths or branches, and confirmed archival. Archival can stop workspace processes and clean up Paseo-managed worktree directories.

Projects with running workspaces appear first by default. The sort menu offers execution end time or name, ascending or descending, and a separate running-first switch. Each project's execution time is the latest reported end time among its workspaces. End times are best-effort status and agent attention timestamps rather than a complete execution history. Projects without a reported time stay last. Creating or opening a project does not change its rank.

Requires Paseo client and daemon 0.11.4 or newer. The plugin uses existing authenticated app connections to query configured online hosts. Only the host serving the plugin needs it installed. That host stores sort, collapse and language preferences shared by its clients. Separate installations keep separate preferences.

The interface supports Chinese and English and a compact phone layout. Desktop and phone-sized browser interactions have automated coverage with sample data. The author confirmed the earlier navigation-only version on desktop and phone after the mobile compatibility fix. New management actions still need live-client verification. Exact app and phone OS versions were not recorded, and this is not a full iOS and Android test matrix. The listing images use fictional sample data.

The plugin reads project, workspace and agent metadata and execution status. It saves display preferences through Paseo settings, opens workspaces through app navigation, and creates, renames or archives workspaces on request through the public SDK. Copy actions write to the current client's clipboard. It does not read conversation bodies or send data to an external service. Offline hosts show only data already loaded in the current screen, with navigation and write actions disabled. The plugin does not replace the built-in workspace sidebar.
